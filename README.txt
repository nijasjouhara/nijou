ASIF NIJAS FAIZY & JOUHARA FATHIMA WEDDING SITE

Files:
- index.html
- style.css
- script.js

This is a zero-cost static website. It is ready to deploy to Vercel.

IMPORTANT:
1. The couple illustrations are CSS-based, so no personal photos are required.
2. To add music later, put an MP3 in the project and set the source in index.html.
3. Replace any gallery placeholders with your own licensed wedding-themed images if desired.
4. Check the spelling of "Pleasent Auditorium" before publishing. The site currently uses exactly what was provided.

Vercel deployment:
- Create a free Vercel account.
- Add this project as a new project.
- Upload/import the folder or connect it to GitHub.
- Deploy with no build command.
